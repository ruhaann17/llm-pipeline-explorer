STAGE 1 Tokenization & Subwords (BPE)

Language models cannot read strings directly. They chop text into discrete chunks called Tokens, map each token to a numeric Token ID in a dictionary, and reconstruct unfamiliar words using ## subwords.

💡 How Subwords Work: If the model knows the full word "espresso", it uses 1 token. But if its vocabulary is restricted or the word is rare (e.g. "peacefully"), it gracefully breaks it into root + subwords like "peace" + "##ful" + "##ly".

STAGE 2 Vector Embeddings & Positional Encoding

Each token ID is looked up in an embedding matrix to retrieve a dense vector (a list of numbers between -1 and +1). Then, Positional Encodings are added so the model knows word order!

💡 Why Positional Encoding Matters: Without position encodings, the sentences "Dog bites man" and "Man bites dog" would produce the exact same bag of vectors! Real LLMs use sinusoidal waves ($PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d})$) or Rotary Position Encodings (RoPE).

STAGE 3 Multi-Head Self-Attention (The Transformer Core)

Attention allows words to look at other words to understand context. For example, in "The animal didn't cross the street because it was too tired", attention teaches the model that "it" refers to the animal, not the street!

STAGE 4 3D Semantic Vector Space (PCA Projection)

Each sentence is mapped to a 64-dimensional semantic embedding vector and compressed into 3D using Principal Component Analysis (PCA). Notice how sentences about Space, Coffee, Nature, and Code form distinct neighborhoods in space!

STAGE 5 Next-Token Probabilities & Generation Loop

The final layer computes a score (Logit) for every word in the dictionary, then converts those logits into probabilities via Softmax with Temperature. Watch how Temperature shapes creativity!
